# my_new_rep

O projeto consiste em visualizar os graficos dos dados retirados do  arquivo 'vehicles_us.csv'.

    - Visualização de Histograma: Gera um grafico de barras que mostra a distribuição da quilometragem dos veiculos anunciados.
    - Visualização em Dispersão: Cruza os dados de quilometragem com os preços para identificar correçoes visuais entre o desgaste e o valor do carro.
    - Utiliza a biblioteca Plotly para permitir que o utilizador faça zoom, explore os dados ao passar o cursor por cima e ajuste os graficos dinamicamente.
    - Os graficos só são processados e exibidos quando o utilizador clicar nos botões especifiicos, otimizando o desempenho do sistema.
